# 메이플 잠재능력 재설정 장사 계산기

메이플스토리 잠재능력 재설정(메소) 장사 수익 계산기입니다.

**사용하기 → https://serin511.github.io/maple-potential-calculator/**

## 특징
- 공식 확률표 기반 3줄 조합 정확 열거 (이탈 1/5·1/20, 중복 제한 옵션 재계산 규칙 반영)
- 유→레 천장 스택(0~107) 이월을 마르코프 체인으로 정확 계산
- 판매/홀드 최적 정지 판정, 미라클데이(등급업 확률 ×2) 지원
- 부위별 특수 잠재: 모자 쿨감, 장갑 크뎀, 장신구 드메, 올스탯(제논)

## 빌드
```bash
npm install
npm run build   # dist/index.html 생성
```
main에 푸시하면 GitHub Actions가 자동으로 빌드해 gh-pages 브랜치로 배포합니다.

## 데이터 출처
- 등급업 확률/천장: 메이플스토리 공식 확률형 아이템 정보
- 옵션 가중치: 잠재능력 공식 확률표 (분수 변환)
- 재설정 비용: 2024.01 개편 공식 표
